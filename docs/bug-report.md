# 금줍줍 버그·이슈 리포트

실제 금줍줍 앱을 사용하면서 발견한 문제를 정리한 문서입니다.

| # | 제목 | 분류 |
|---|---|---|
| 1 | 광고 종료 후 X 버튼을 누르면 검은 화면에서 멈춤 | 버그 |
| 2 | 미션 완료 후 리워드 [받기] 버튼이 늦게 활성화됨 | 이슈 (상태 갱신 지연) |

## 1. 광고 종료 후 X 버튼을 누르면 검은 화면에서 멈춤

### 요약
광고 시청이 끝난 뒤 닫기(X) 버튼을 누르면 앱 화면으로 돌아오지 않고 검은 화면이 유지된다. 앱을 완전히 종료한 뒤 다시 실행해야 정상으로 돌아온다.

### 환경
| 항목 | 내용 |
|---|---|
| 플랫폼 | Android 앱 |
| 기기 / OS 버전 | 확인 필요 |
| 앱 버전 | 확인 필요 |

### 재현 절차
1. 앱 실행 후 홈 화면으로 이동
2. 광고 보상이 있는 항목에서 광고 시청 (어떤 항목인지는 특정하지 못함)
3. 광고를 끝까지 시청
4. 광고의 X(닫기) 버튼을 누름

### 기대 결과
광고가 닫히고 이전 화면으로 돌아오며, 보상이 반영된다.

### 실제 결과
- 검은 화면에서 멈추고 이전 화면으로 돌아오지 않음
- 앱을 강제 종료 후 다시 실행해야 복구됨

### 발생 빈도
간헐적, 약 10회 중 1회

### 추정 원인
앱 내부 코드를 확인할 수 없어 확정할 수는 없으며, 비슷한 증상에서 흔한 원인을 바탕으로 추정했다.

| 추정 원인 | 설명 |
|---|---|
| 광고 SDK 콜백 순서 문제 | 광고 SDK는 "보상 지급"과 "광고 닫힘" 이벤트를 따로 보내며, 순서가 항상 같지 않다. 앱이 특정 순서만 가정하면 로딩 화면 등을 닫지 못하고 멈출 수 있다. 간헐적으로 발생하는 점과 맞는다. |
| 특정 광고 네트워크·광고 소재 문제 | 여러 광고 네트워크의 광고를 번갈아 노출할 경우, 특정 네트워크나 플레이어블 광고에서만 닫힘 처리에 문제가 있을 수 있다. |
| 메모리 부족으로 앱 화면이 정리됨 | 무거운 광고를 보는 동안 Android가 뒤에 있던 앱 화면을 메모리에서 정리하고, 복귀 시 화면을 다시 그리지 못했을 수 있다. |

### 추가로 확인할 것
- 검은 화면에서 뒤로 가기 버튼으로 복구되는지
- 앱 재실행 후 보상이 지급되어 있는지 (지급되지 않았다면 보상 누락 문제로 심각도가 높아짐)
- 특정 형태의 광고(플레이어블, 영상)에서만 발생하는지

### 모작에 반영할 점
- 광고가 닫히면 이벤트 순서와 관계없이 항상 이전 화면으로 돌아오도록 처리
- 보상은 중복 방지 키(`key`)로 한 번만 지급되도록 처리

## 2. 미션 완료 후 리워드 [받기] 버튼이 늦게 활성화됨

### 요약
일반 스탬프의 미션(룰렛, 뽑기 등)을 완료한 뒤 리워드를 받으러 가면 [받기] 버튼이 바로 활성화되지 않는다. 뒤로 가기로 화면을 몇 번 오가야 뒤늦게 활성화된다. 반면 푸시 알림으로는 "리워드를 받을 수 있다"는 알림이 먼저 온다.

### 환경
| 항목 | 내용 |
|---|---|
| 플랫폼 | Android 앱 |
| 기기 / OS 버전 | 확인 필요 |
| 앱 버전 | 확인 필요 |

### 재현 절차
1. 일반 스탬프 화면에서 미션(룰렛, 뽑기 등) 하나를 선택
2. 미션을 완료
3. 리워드 수령 화면으로 돌아옴

### 기대 결과
미션을 완료하고 돌아오면 [받기] 버튼이 바로 활성화된다.

### 실제 결과
- [받기] 버튼이 비활성화 상태로 남아 있음
- 뒤로 가기로 다른 화면에 갔다가 돌아오기를 반복하면 뒤늦게 활성화됨
- 그 사이 "리워드를 받을 수 있다"는 푸시 알림은 이미 도착함

### 분류
앱이 멈추거나 리워드가 사라지지는 않으므로 치명적인 버그는 아니다. 다만 화면 상태와 실제 상태(푸시 알림)가 어긋나 사용자가 혼란을 느끼는 이슈다.

### 추정 원인
앱 내부 코드를 확인할 수 없어 확정할 수는 없으며, 비슷한 증상에서 흔한 원인을 바탕으로 추정했다.

| 추정 원인 | 설명 |
|---|---|
| 화면으로 돌아올 때 상태를 다시 불러오지 않음 | 미션 상태를 화면이 처음 열릴 때만 불러오고, 미션을 마치고 돌아왔을 때는 다시 불러오지 않을 수 있다. 화면을 오가다 보면 어느 순간 새로 불러오면서 활성화된다. |
| 서버의 미션 완료 처리가 늦게 끝남 | 미션 완료가 서버에서 비동기로 처리되면, 돌아온 직후에는 아직 "미완료" 상태를 받아 온다. 푸시 알림은 서버 처리가 끝난 시점에 보내지므로 알림이 먼저 도착한다. |
| 이전 응답을 캐시로 재사용 | 미션 상태 응답을 캐시해 두었다가 그대로 보여 주면, 완료 이후에도 한동안 예전 상태가 표시된다. |

### 추가로 확인할 것
- 활성화되기까지 걸리는 시간이 대략 일정한지 (일정하면 서버 처리 지연 쪽)
- 푸시 알림을 눌러서 들어가면 바로 활성화되어 있는지
- 앱을 완전히 껐다 켜면 바로 활성화되는지 (바로 되면 화면 갱신 문제 쪽)

### 모작에 반영할 점
- 미션·보상 화면은 화면에 다시 들어올 때마다 최신 상태로 갱신
- 버튼 활성화 여부는 따로 저장하지 않고, 실제 보상 상태(내역의 `key`)에서 계산해 화면과 실제 상태가 어긋나지 않게 처리
