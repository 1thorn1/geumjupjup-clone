# 금줍줍 분석

## 하단 탭 구성
홈 / 만보기 / 교환(선물) / 설정

## 핵심 루프
금이 시간에 따라 저절로 채굴됨 → (상한에 차면 멈춤) → 광고 보고 금 줍기로 지갑에 적립 → 다시 채굴
- 미션·이벤트로 채굴 속도를 올릴 수 있음
- 출석·메시지함 보상도 지갑에 적립 → 상품권 교환

## 화면별 정리
### 홈
![홈](images/01-home.png)
- 상단: 프로필 / 보유 금(원화로 표시, 누르면 금 내역 화면으로 이동) / 메시지함
- 이벤트 배너 (예: 신규 가입 유저 출석 이벤트)
- 채굴 카드: 채굴 중인 금의 양(채굴량), 속도 배수(%로 표시)
- 채굴 속도 증가시키기: 드릴·폭발·곡괭이 등 미션 목록

### 채굴
- 앱을 켜 두지 않아도 시간에 따라 채굴량이 쌓임 (정확한 속도는 확인 못 함)
- 채굴량이 상한에 차면 더 쌓이지 않고 "금을 모두 모아 휴식중이에요" 표시
- 미션·이벤트에 참여하면 채굴 속도가 빨라짐

### 출석 체크
- 출석 체크 → 광고 시청(플레이어블 광고) → 광고 종료 후 도장 찍힘
- 도장 찍히는 모션 후 "출석 완료" 표시, 버튼 비활성화 (하루 1회)

### 광고 보고 금 줍기
- 언제든 누를 수 있음 → 광고 시청 → 그때까지 쌓인 채굴량이 지갑에 적립
- 적립 후 채굴량은 0부터 다시 쌓임

### 메시지함
- 상단에 지금까지 캔 금의 양 표시
- 보상이 메시지 형태로 들어옴
- [받기] 누르면 적립되고 버튼이 [삭제]로 바뀜 (같은 보상 재수령 불가)

### 금 내역 (보유 금 클릭)
- 7일 / 14일 / 30일 기간별로 번 금 그래프
- 하단에서 [상세 내역] / [구매 내역] 선택해 목록 확인

### 교환 (선물 탭)
- 보유 금과 원화 환산 금액 표시
- 상품 예: 네이버페이 상품권 10,000원
- 금이 부족하면 "보유하신 금이 부족합니다." 팝업 + [닫기]
- 실제 교환 흐름은 잔액 부족으로 확인하지 못함

### 금 표시 방식
- 보유 금을 소수점 아래 12자리까지 표시하고 원화로 환산
- 예: `0.000044886287g` → `7원`

## 내 모작에서 구현할 범위
- 탭: 홈 / 교환 / 설정 (만보기는 "준비 중" 화면으로 대체)
- 채굴: 시간에 따라 쌓이고 상한에 차면 멈춤, 광고 보고 금 줍기로 지갑에 적립
  - 채굴량은 타이머로 더하지 않고, 시작 시각을 저장해 두고 경과 시간으로 계산
- 채굴 속도 올리기: 미션 1~2개로 속도 배수 적용 (여유 시)
- 그 밖의 적립: 출석 체크, 메시지함 보상 받기
- 광고는 실제 SDK 없이 "광고 시청 중" 타이머 화면으로 대체 (mock)
- 금 내역: 상세 내역 / 구매 내역 목록 (기간별 그래프는 여유 시 가산점으로)
- 교환: 잔액 부족 시 안내 팝업, 충분하면 교환 확인 후 차감
- 금은 0.000000000001g(10⁻¹²g)을 1로 보는 정수로 저장
