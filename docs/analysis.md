# 금줍줍 분석

실제 금줍줍 앱을 설치해서 써 보고 화면·흐름을 정리한 문서.
코드를 어떻게 짰는지는 [설계 문서](design.md), 사용하다 발견한 문제는 [버그 리포트](bug-report.md)에 있다.

## 하단 탭 구성
홈 / 만보기 / 선물 / 프로필 (아이콘만 있고 글자 없음, 선택된 탭은 보라색)

## 핵심 루프
금이 시간에 따라 저절로 채굴됨 → (상한에 차면 멈춤) → 광고 보고 금 줍기로 지갑에 적립 → 다시 채굴
- 출석·행운추첨·미션·메시지함 보상은 **금이 아니라 채굴 속도(%)**를 올려 준다
- 속도가 빠를수록 금이 빨리 쌓임 → 금 줍기로 지갑에 적립 → 선물 탭에서 상품 교환
- 즉, 지갑 잔액이 늘어나는 길은 사실상 "광고 보고 금 줍기" 하나

## 화면별 정리
### 홈
- 상단 바 (모든 탭 공통): 금줍줍 로고 / 보유 금 / 메시지함
  - 보유 금은 원화(예: `114원`)와 g(예: `0.000731…g`)가 몇 초마다 위아래로 번갈아 바뀜
  - 누르면 금 내역 화면으로 이동
- 이벤트 배너 (예: 신규 가입 유저 출석 이벤트)
- 채굴 카드: 속도 배수(% 크게), 채굴 상태, 채굴량, 아래에 걸친 [광고 보고 금 줍기] 버튼
- ▶ 채굴 속도 증가시키기: 노란 판에 미션 타일 7개 (윗줄 3개, 아랫줄 4개) + [가이드]
- "미션달성하고 보상받기" 카드: 대표 미션 하나와 받을 수 있는 속도 합계
- 행운추첨 / 출석체크 바로가기

### 채굴
- 앱을 켜 두지 않아도 시간에 따라 채굴량이 쌓임 (정확한 속도는 확인 못 함)
- 채굴량이 상한에 차면 더 쌓이지 않고 "금을 모두 모아 휴식중이에요" 표시
- 출석·행운추첨·미션 보상을 받으면 채굴 속도가 빨라짐

### 출석 체크
- 출석 체크 → 광고 시청(플레이어블 광고) → 광고 종료 후 도장 찍힘
- 도장 찍히는 모션 후 "출석 완료" 표시, 버튼 비활성화 (하루 1회)
- 보상은 채굴 속도 증가

### 광고 보고 금 줍기
- 언제든 누를 수 있음 → 광고 시청 → 그때까지 쌓인 채굴량이 지갑에 적립
- 적립 후 채굴량은 0부터 다시 쌓임

### 메시지함
- 상단에 지금까지 캔 금의 양 표시
- 보상이 메시지 형태로 들어옴
- [받기]를 누르면 보상(채굴 속도)을 받고 버튼이 [삭제]로 바뀜 (같은 보상 재수령 불가)

### 행운추첨
- 회차제 추첨 (예: 106회차). 응모 마감·개표 시각이 정해져 있음
- [광고 보고 참여하기]로 응모. 광고를 정해진 횟수만큼 봐야 응모 완료 ("광고 1번 더 보면 응모 완료!")
- 개표 후 등수별 채굴 속도 보너스: 1등 +300%, 2등 +200%, 3등 +100%, 참여상(전원) +10%

### 채굴 속도 미션 (오퍼월)
- 홈의 드릴·폭발·마법구슬·곡괭이·마법봉·광차·보따리 미션 타일
- 누르면 외부 게임 설치, 앱 회원가입 같은 광고주 캠페인과 연결됨
- 미션 상세: 큰 이미지, 참여 기한, 단계 목록 (예: 5레벨 클리어 → +75%, 10레벨 → +15% …)
- 단계를 완료하면 바로가 아니라 잠시 뒤 채굴 속도가 지급됨

### 금 내역 (보유 금 클릭)
- 7일 / 14일 / 30일 기간별로 번 금 그래프
- 하단에서 [상세 내역] / [구매 내역] 선택해 목록 확인

### 교환 (선물 탭)
- 위쪽: 보유 금(g) 카드 ⇅ 원화 환산 카드, [금시세 확인]
- ▼ 금 상품 (삼성금거래소 골드바) / ▼ 기프티콘 (브랜드별)
- 브랜드마다 상품 카드가 가로로 스크롤됨. 카드 오른쪽 위에 `+10,000%` 같은 배지
- 첫 분류 제목 옆에 [가이드] [구매 내역]
- 금이 부족하면 "보유하신 금이 부족합니다." 팝업 + [닫기]
- 실제 교환 흐름은 잔액 부족으로 확인하지 못함

### 금 표시 방식
- 보유 금을 소수점 아래 12자리까지 표시하고 원화로 환산
- 예: `0.000044886287g` → `7원`

## 내 모작에서 구현할 범위 (처음 계획, 10/22)
- 탭: 홈 / 교환 / 설정 (만보기는 "준비 중" 화면으로 대체)
- 채굴: 시간에 따라 쌓이고 상한에 차면 멈춤, 광고 보고 금 줍기로 지갑에 적립
  - 채굴량은 타이머로 더하지 않고, 시작 시각을 저장해 두고 경과 시간으로 계산
- 채굴 속도 올리기: 미션 1~2개로 속도 배수 적용 (여유 시)
- 그 밖의 적립: 출석 체크, 메시지함 보상 받기
- 광고는 실제 SDK 없이 "광고 시청 중" 타이머 화면으로 대체 (mock)
- 금 내역: 상세 내역 / 구매 내역 목록 (기간별 그래프는 여유 시 가산점으로)
- 교환: 잔액 부족 시 안내 팝업, 충분하면 교환 확인 후 차감
- 금은 0.000000000001g(10⁻¹²g)을 1로 보는 정수로 저장

## 구현하며 바뀐 점
| 처음 계획 | 실제 구현 | 이유 |
|---|---|---|
| 출석·메시지함 보상을 금으로 지급 | 출석·룰렛·오퍼월 보상은 **채굴 속도(%)** | 앱을 더 써 보니 미션 보상은 금이 아니라 속도였음. 화면·구조를 실제 앱과 맞춤 |
| 탭 3개 (홈 / 교환 / 설정) | 탭 4개 (홈 / 만보기 / 선물 / 프로필) | 실제 앱 배치와 맞춤. 만보기·프로필은 "준비 중" |
| 메시지함 보상 받기 | 메시지함은 "준비 중" | 적립 2종 이상은 출석·룰렛으로 충족. 메시지 보상도 결국 속도라서 출석과 구조가 같음 |
| (계획 없음) | 행운추첨 → **룰렛** | 회차제 추첨은 개표 시각까지 기다려야 해서 시연이 어려움. 광고 보고 돌리면 바로 결과가 나오는 룰렛으로 단순화 (하루 3회, 첫 회 무료) |
| 미션 1~2개 (여유 시) | 미션 타일 7개는 "준비 중", **냥탈출 오퍼월 하나** | 타일 미션은 외부 게임·광고주와 연동되는 부분이라 범위 밖. 선택 구현인 Mock 오퍼월(참여 중 → 지급 대기 → 지급 완료)은 냥탈출로 시연 |
| (계획 없음) | **개발자 모드** (로고 20번 탭) | 채굴만으로는 상품 교환까지 금을 모으기 어려워서, 금·속도를 넣어 교환을 시험하는 화면 추가 |
| 금 내역 기간별 그래프 (여유 시) | 구현 안 함 | 필수 범위를 먼저 끝내느라 시간 부족 |
