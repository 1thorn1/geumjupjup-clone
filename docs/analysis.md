# 금줍줍 분석

## 하단 탭 구성
홈 / 만보기 / 교환(선물) / 설정

## 핵심 루프
행동(출석, 광고 시청) → 금 적립(메시지함 보상 포함) → 상품권 교환

## 화면별 정리
### 홈
![홈](images/01-home.png)
- 상단에 보유 금 표시 (누르면 금 내역 화면으로 이동)
- 출석 체크, 광고 보고 금 줍기 등 적립 진입점

### 출석 체크
- 출석 체크 → 광고 시청(플레이어블 광고) → 광고 종료 후 도장 찍힘
- 도장 찍히는 모션 후 "출석 완료" 표시, 버튼 비활성화 (하루 1회)

### 광고 보고 금 줍기
- 광고 3개를 모두 보면 "채굴량 ~을 모았다" 버튼 활성화
- 받은 뒤에도 다시 광고를 보면 재활성화 (반복 가능)
- 조건을 채우기 전에는 버튼 비활성화

### 메시지함
- 상단에 지금까지 캔 금의 양 표시
- 보상이 메시지 형태로 들어옴
- [받기] 누르면 적립되고 버튼이 [삭제]로 바뀜 (같은 보상 재수령 불가)

### 금 내역 (보유 금 클릭)
- 7일 / 14일 / 30일 기간별로 번 금 그래프
- 하단에서 [상세 내역] / [구매 내역] 선택해 목록 확인

### 교환 (선물 탭)
- 보유 금과 원화 환산 금액 표시
- 상품 예: 네이버페이 상품권 10,000원
- 금이 부족하면 "보유하신 금이 부족합니다." 팝업 + [닫기]
- 실제 교환 흐름은 잔액 부족으로 확인하지 못함

### 금 표시 방식
- 보유 금을 소수점 아래 12자리까지 표시하고 원화로 환산
- 예: `0.000044886287g` → `7원`

## 내 모작에서 구현할 범위
- 탭: 홈 / 교환 / 설정 (만보기는 "준비 중" 화면으로 대체)
- 적립 3종: 출석 체크, 광고 3개 보고 금 줍기, 메시지함 보상 받기
- 광고는 실제 SDK 없이 "광고 시청 중" 타이머 화면으로 대체 (mock)
- 금 내역: 상세 내역 / 구매 내역 목록 (기간별 그래프는 여유 시 가산점으로)
- 교환: 잔액 부족 시 안내 팝업, 충분하면 교환 확인 후 차감
- 금은 0.000000000001g(10⁻¹²g)을 1로 보는 정수로 저장
